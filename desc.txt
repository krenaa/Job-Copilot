Project: Resume Gap Analyzer
One-line pitch

An agent that compares a job description against a resume and returns a clear gap list — what's missing, what's weak, what's a strong match — using a human-in-the-loop check before finalizing output.

Why this exists

Built to use during an active job search: paste a JD, paste a resume, get a structured gap analysis instead of guessing what to tweak per application.

Hard scope — do not exceed this

This is a 1-day build. Every item below is IN. Nothing else gets added until this list is fully done and tested.

In scope
Input
Two text boxes: paste job description, paste resume text.
No file upload. No parsing PDFs/DOCX. Plain text only.
LangGraph flow
Node 1 — Extract requirements: pull required skills/keywords/experience from the JD.
Node 2 — Extract candidate profile: pull actual skills/experience from the resume text.
Node 3 — Compare: produce three buckets — Missing, Weak (mentioned once / no project backing it), Strong (clear match).
interrupt() before final output — human-in-the-loop confirmation step (same HITL pattern as AmbientAI), so the user can adjust before the result is finalized.
Output
Plain structured list grouped into Missing / Weak / Strong.
No scoring, no percentages, no fancy formatting — a readable list is enough.
UI
Simple Streamlit form OR a basic React form. Whichever is faster to wire up today. No styling pass.
README
Why it was built, one screenshot, one example run (real JD + real resume, anonymized if needed).

Tech stack (reuse what's already known — nothing new to learn under time pressure)
LangGraph (StateGraph + interrupt() for HITL, same pattern as AmbientAI)
FastAPI backend (if using React) or plain Streamlit app (if going that route — pick one, don't build both)

No database required for v1 — state can be in-memory for a single session
